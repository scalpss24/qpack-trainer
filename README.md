# QPack Тренажёр (`Excel → .qpack → PWA / Android APK`)

Набор из двух компонентов:
1. **Python-конвертер (`converter/`)** — преобразует файлы `.xlsx` (в том числе со сложной и неоднородной разметкой, цветами, символами `+`/`*` и встроенными картинками) в переносимый контейнер `.qpack`.
2. **Офлайн-приложение (`app/`)** — мобильный тренажёр (работает как PWA в браузере и как нативное Android-приложение через Capacitor APK) с локальным хранением прогресса в `IndexedDB`.

---

## 1. Подготовка и конвертация Excel (`.xlsx → .qpack`)

### Установка зависимостей (один раз)
```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### Запуск конвертера
```powershell
.\.venv\Scripts\python.exe -m converter.cli путь\к\файлу.xlsx -o tests.qpack --title "Сестринское дело" --show-warnings
```

Параметры:
- `-o`, `--output` — путь к итоговому `.qpack` файлу (по умолчанию рядом с `.xlsx`).
- `--title` — название пакета, которое отобразится в приложении.
- `--package-id` — стабильный ID пакета. Если при обновлении тестов использовать тот же `--package-id`, пользовательский прогресс, «Избранное» и заметки сохранятся.
- `--show-warnings` — вывести вопросы, в которых не обнаружен маркер правильного ответа.

### Какую разметку Excel понимает конвертер
Парсер поддерживает **горизонтальные** и **вертикальные** таблицы:
- **Горизонтальная таблица**: 1-я строка — заголовки `№ | Вопросы | Вариант 1 | Вариант 2 | ...` (или `№ | Вопросы | Ответы` для карточек).
- **Вертикальная таблица**: вопрос жирным шрифтом (или с номером в 1-м столбце), варианты ответов строками ниже.
- **Маркеры правильного ответа** (в порядке приоритета):
  1. Цветная заливка ячейки (например, жёлтая `#FFFF00`).
  2. Символ `+` в начале, конце или в соседнем столбце.
  3. Символ `*` (если не используется как маркер списка у всех вариантов сразу).
  4. Цветной шрифт (например, красный) на правильном варианте.
  5. Жирный шрифт на правильном варианте (если остальные не жирные).
- **Несколько правильных ответов** → тип вопроса автоматически становится `multiple_choice`.
- **Лист вида `62 вопр`** (один ответ на вопрос или заголовки `Вопросы | Ответы`) → карточки `flashcard`.
- **Встроенные изображения** на листах автоматически сохраняются в папку `images/` внутри `.qpack` без сжатия и привязываются к ближайшему вопросу.

## 2. Как пользоваться приложением (PWA и Android APK)

### Локальный запуск в браузере (для проверки на ПК)
```powershell
.\.venv\Scripts\python.exe -m http.server 8765 --directory app
```
Откройте `http://localhost:8765`. Для мобильного вида можно включить режим смартфона в DevTools (`F12` → `Ctrl+Shift+M`) или открыть адрес по локальной сети с телефона.

### Работа в приложении
1. **Импорт `.qpack` или `.json`**: нажмите **«Выбрать .qpack / .json файл»** (или перетащите файл в окно браузера) и выберите `.qpack` либо готовый `manifest.json`.
2. **Выбор тем и фильтров**: откройте загруженный пакет. Выберите фильтр:
   - **Все** — вся база;
   - **Новые** — вопросы, на которые ещё не отвечали;
   - **Ошибки** — вопросы, где последний ответ был неверным;
   - **Избранное** — отмеченные звёздочкой `★`.
   Можно включить/отключить перемешивание вопросов и вариантов ответов.
3. **Тренировка**:
   - В тестах с 1 ответом (`single_choice`) выбор сразу показывает результат.
   - В тестах с несколькими ответами (`multiple_choice`) отметьте нужные варианты и нажмите **«Проверить»**.
   - В карточках (`flashcard`) нажмите **«Показать ответ»**, затем оцените себя: **«Знаю»** или **«Повторить»**.
   - Картинки в вопросах увеличиваются по нажатию.
   - Под каждым вопросом есть раскрывающееся поле **«Личная заметка / шпаргалка»** — сохраняется автоматически.
4. **Резервная копия прогресса**: кнопка `⇅` в правом верхнем углу позволяет выгрузить `my_progress_backup.json` (или скопировать JSON в буфер) и перенести прогресс на другое устройство.

> **Обновление тестов без потери прогресса:** при загрузке новой версии `.qpack` с тем же `package_id` вопросы обновляются, а статистика, «Избранное» и заметки остаются на месте (привязка идёт по хэшу текста вопроса `question_id`).

## 3. Загрузка на GitHub и автоматическая сборка Android APK

Репозиторий уже настроен для сборки Android APK с помощью **Capacitor** и **GitHub Actions** (локально устанавливать Android Studio не требуется).

### Шаг 1. Загрузите проект на GitHub
Создайте пустой репозиторий на GitHub (например, `qpack-trainer`), затем в папке проекта выполните:
```powershell
git init
git add .
git commit -m "Initial commit: QPack converter, PWA and APK workflow"
git branch -M main
git remote add origin https://github.com/<ваш-логин>/<имя-репозитория>.git
git push -u origin main
```

### Шаг 2. Скачайте готовый APK
1. После `git push` перейдите в репозиторий на GitHub и откройте вкладку **Actions**.
2. Дождитесь завершения workflow **Test & Build Android APK** (сначала прогоняются тесты Python-конвертера, затем собирается APK — обычно 2–4 минуты).
3. Откройте завершившийся запуск, прокрутите вниз до раздела **Artifacts** и скачайте **`qpack-trainer-debug-apk`**.
4. Распакуйте архив и перенесите `qpack-trainer-debug.apk` на Android-смартфон, откройте файл и разрешите установку из неизвестных источников.

*(Также сборку можно запускать вручную в любой момент через **Actions → Test & Build Android APK → Run workflow**.)*

## 4. Промпт для любого AI-чата (прямая генерация файла для приложения)

Если хотите просто закинуть исходные тесты (Excel, Word, PDF или текст) в любой чат (ChatGPT, Gemini, Claude) и сразу получить готовый файл для приложения без запуска Python на своём ПК, используйте этот промпт:

```text
Преобразуй приложенные тесты/вопросы в файл `tests_manifest.json` строго по формату ниже (его можно напрямую загрузить в приложение QPack Тренажёр, а если у тебя есть Python — дополнительно упакуй его в ZIP-архив `tests.qpack` с файлом `manifest.json` внутри).

Требования к JSON:
{
  "format_version": "1.0",
  "package_id": "латинский_id_пакета",
  "title": "Читаемое название дисциплины/пакета",
  "created_at": "2026-11-24T00:00:00Z",
  "categories": [
    {
      "id": "cat_01",
      "title": "Название темы или листа",
      "question_count": 10
    }
  ],
  "questions": [
    {
      "id": "уникальный_хэш_или_12_символов_sha1_от_нормализованного_текста_вопроса",
      "category_id": "cat_01",
      "type": "single_choice",
      "text": "Чистый текст вопроса без номера (1., 25)) и лишних пробелов",
      "images": [],
      "options": [
        { "id": "opt_1", "text": "Чистый вариант без A), 1., +, *", "is_correct": true },
        { "id": "opt_2", "text": "Другой вариант", "is_correct": false }
      ],
      "explanation": null
    }
  ]
}

Правила:
1. `type`:
   - `"single_choice"` — 1 правильный вариант;
   - `"multiple_choice"` — 2+ правильных вариантов;
   - `"flashcard"` — карточка «Вопрос — Эталонный ответ» (`options`: один элемент `{"id": "opt_1", "text": "Эталонный ответ", "is_correct": true}`).
2. Очисти текст вопросов от номеров (`1.`, `12)`), а варианты — от префиксов/суффиксов (`A.`, `1)`, `*`, `+`, `+1`).
3. Проверь, что у каждого вопроса есть хотя бы один вариант с `"is_correct": true`.
4. Выдай готовый файл для скачивания (`tests.qpack` или `tests_manifest.json`).
```
