# Архитектурная спецификация: Конвертер Excel → Пакет тестов (.qpack) → Мобильное приложение

## 1. Общая схема работы (Pipeline)
1. **Этап подготовки (Десктоп / Конвертер):**
   - Исходный файл `.xlsx` (со сложной и неоднородной разметкой: заливка ячеек, цвет шрифта, символы `+`, встроенные изображения) обрабатывается скриптом-конвертером (на Python).
   - Скрипт извлекает тексты вопросов, варианты ответов, определяет правильный ответ по визуальным или текстовым маркерам, выгружает встроенные в листы изображения и привязывает их к соответствующим вопросам.
   - На выходе формируется единый переносимый файл-контейнер с расширением **`.qpack`** (по сути — стандартный ZIP-архив без сжатия для картинок).

2. **Этап доставки:**
   - Готовый файл `.qpack` отправляется пользователю по электронной почте или в мессенджер.

3. **Этап тренировки (Мобильное приложение):**
   - Приложение умеет импортировать любые файлы `.qpack` из памяти устройства или напрямую через системное меню «Открыть в...» / «Поделиться».
   - Внутри приложения пользователь может переключаться между загруженными пакетами (дисциплинами) и темами (листами Excel).
   - Прогресс, избранное, история ошибок и личные заметки пользователя сохраняются в локальной базе данных приложения с привязкой к `question_id` и не перезаписываются при обновлении пакета.

## 2. Внутренняя структура контейнера `.qpack`
Файл `nazvanie_testa.qpack` представляет собой ZIP-архив следующей структуры:

```text
test_package.qpack (ZIP)
├── manifest.json       # Метаданные пакета и полный массив вопросов
└── images/             # Папка с извлеченными из Excel картинками (опционально)
    ├── q_001_img1.png
    └── q_045_img1.jpg
```

## 3. Схема данных `manifest.json`

```json
{
  "format_version": "1.0",
  "package_id": "sestrinskoe_delo_2024_stage1",
  "title": "Сестринское дело — Все тесты (1 этап 2024 г.)",
  "created_at": "2026-11-22T19:00:00Z",
  "categories": [
    {
      "id": "cat_01",
      "title": "Тесты для всех 2024",
      "question_count": 320
    },
    {
      "id": "cat_02",
      "title": "Акушерство 2024 г",
      "question_count": 150
    }
  ],
  "questions": [
    {
      "id": "a1b2c3d4e5f6",
      "category_id": "cat_01",
      "type": "single_choice",
      "text": "Укажите нормальную частоту дыхательных движений у взрослого в покое:",
      "images": [
        "images/q_001_img1.png"
      ],
      "options": [
        { "id": "opt_1", "text": "16–20 в минуту", "is_correct": true },
        { "id": "opt_2", "text": "25–30 в минуту", "is_correct": false },
        { "id": "opt_3", "text": "10–12 в минуту", "is_correct": false },
        { "id": "opt_4", "text": "30–35 в минуту", "is_correct": false }
      ],
      "explanation": "Пояснение или комментарий (если присутствовал в базе, иначе null)"
    }
  ]
}
```

### Ключевые правила формирования полей:
- **`id` вопроса:** Детерминированный хэш (например, MD5/SHA-1 от нормализованного текста вопроса). Это гарантирует, что если пользователь загрузит обновленный `.qpack` с исправленными опечатками, его статистика, «Избранное» и личные заметки к вопросам сохранятся.
- **`type` (Тип вопроса):**
  - `single_choice` — выбор одного правильного ответа (стандартный тест).
  - `multiple_choice` — выбор нескольких правильных ответов (если в Excel отмечено более 1 правильного варианта).
  - `flashcard` — карточка «Вопрос — Эталонный ответ» (для листов наподобие `62 вопр`, где даны развернутые ответы без вариантов выбора).
- **Очистка текста:** Конвертер автоматически удаляет мусорные префиксы/суффиксы разметки (`+`, `*`, `1)`, `A.`, лишние пробелы и переносы строк), чтобы мобильное приложение могло безопасно перемешивать варианты ответов.

## 4. Хранение пользовательских данных в мобильном приложении
В локальной БД смартфона (SQLite / IndexedDB) отдельно от пакетов `.qpack` хранится таблица `user_progress`:
- `question_id` — связь с вопросом.
- `status` — `unseen` (новый), `learned` (выучен), `mistake` (ошибка).
- `attempts_count` / `correct_count` — счетчики попыток.
- `is_favorite` — флаг «Избранное» (boolean).
- `user_note` — текстовая заметка/шпаргалка, которую пользователь написал сам для этого вопроса.
- `last_answered_at` — дата последней тренировки (для интервального повторения).

Для надежности в приложении предусмотрена функция **Экспорт / Импорт прогресса** в отдельный файл `my_progress_backup.json`.
